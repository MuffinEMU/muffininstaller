Or with your own Apple ID

Once MuffinEMU is installed, it signs and renews itself with your own Apple ID — the official MuffinInstaller, built in.

  1. Install MuffinEMU above, or with SideStore / AltStore.
  2. Open Settings > Storage > MuffinInstaller in the app.
  3. Connect LocalDevVPN. On iOS 27 it pairs on-device; on 17.4–26, import a pairing file once.
  4. Sign in with your Apple ID, or use your own certificate.
  5. MuffinEMU keeps itself installed and updated from then on — refresh before a free Apple ID's 7 days run out, and install new releases automatically.
